# AI/R Harness Setup

_Configurando um Outer Harness na prática._

## Bem-vindo

- **Para quem é:** AI Champions e desenvolvedores que vão adotar o Outer Harness nos projetos dos seus squads.
- **O que você vai aprender:** como a skill `air-harness-setup` gera o harness sob medida para um projeto, e como manter esse harness vivo com o uso.
- **O que você vai construir:** um Outer Harness completo (`AGENTS.md` + rules) num projeto real, com o agente que você escolher: Claude Code, Kiro, GitHub Copilot ou AI/C Reasoning.
- **Pré-requisitos:** Git, uma conta GitHub com acesso à organização AIR-Modern-Studio e um dos quatro agentes instalado na sua máquina.
- **Onde:** na sua máquina, com o repositório clonado.

Neste exercício, você vai:

1. Montar a pasta-mãe com o pacote do seu agente ao lado do código.
1. Gerar e validar o `AGENTS.md` com a skill.
1. Aprovar rules sob medida para o projeto.
1. Usar o harness numa tarefa e ajustar o documento com o que aprendeu.

### Como iniciar este exercício

Copie o exercício para a sua conta como repositório **privado**, aguarde **cerca de 20 segundos** e **atualize a página**. As instruções chegam numa issue do seu repositório.
